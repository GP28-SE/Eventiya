User Journey Map - Eventiya

Persona: Amara - University student, 22, Colombo. Frequent event-goer, mobile-first user.

Scenario: Discovering, booking, attending, and reviewing an event on Eventiya.


Row Stage 1: Discovery Stage 2: Exploration Stage 3: Decision Stage 4: Booking Stage 5: Attendance Stage 6: Post-Event
User Actions - Sees event link shared on WhatsApp
- Searches "events this weekend Colombo"
- Lands on Eventiya via Google 		- Browses event listings and filters by category
- Reads event description and lineup
- Views organiser profile and past events 		- Compares ticket tiers (Early Bird vs. VIP)
- Checks friends availability via group chat
- Reads reviews from past attendees 		- Selects ticket type and quantity
- Creates or logs in to Eventiya account
- Pays via e-wallet or card
- Receives e-ticket and booking confirmation 		- Opens QR e-ticket at venue gate
- Gets ticket scanned for entry
- Shares event updates on social media
- Rates the event experience in-app 		- Receives follow-up email with highlights
- Leaves a written review on Eventiya
- Browses related upcoming events
- Refers the app to friends
Touchpoints - Social media and WhatsApp links
- Google search results
- Eventiya landing page 		- Event listing and search page
- Event detail page
- Organiser public profile page 		- Ticket tier comparison panel
- User reviews section
- Share-with-friends feature 		- Checkout and seat selection flow
- Login and registration pages
- Payment gateway
- Confirmation email and in-app notification 		- E-ticket QR screen
- Venue gate scanner
- In-app live rating prompt 		- Post-event email digest
- In-app review and rating form
- Personalised event recommendations
Pain Points - Broken or expired shared links
- Poor SEO makes platform hard to find
- Slow initial page load 		- Cluttered listings with no smart filters
- Missing key info such as map, lineup, dress code
- No way to verify organiser credibility 		- Unclear pricing with hidden service fees
- No group booking or split-pay option
- Too few or unverified reviews 		- Forced account creation before payment
- Limited payment methods accepted
- Checkout timeout causes seat hold loss
- No instant booking confirmation 		- QR code fails offline or in low light
- Long queues at the scanner point
- Rating prompt appears too early in the event 		- Generic follow-up emails with no personalisation
- No clear refund or dispute resolution path
- No loyalty reward for repeat users
Emotions Curious and intrigued Excited and engaged Uncertain and hesitant Stressed and impatient Thrilled and happy Satisfied and reflective
Opportunities Shareable deep-links with optimised preview cards to drive viral discovery Smart filters by genre, price, and distance; verified organiser badges Group invite links and split-payment flow to reduce decision friction Guest checkout option, more payment methods, and real-time seat-hold countdown Offline QR support and multi-scanner entry to eliminate gate bottlenecks Personalised recap emails, loyalty points, and AI-driven event recommendations
